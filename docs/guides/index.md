# Guides

Each guide shows how to do one thing, with a complete example you can copy.
Every example is a real file in the package's repository, run by its test
suite.

| Guide | Use it when you want to |
| ----- | ----------------------- |
| [Layout](layout.md) | Put fields side by side, group them into sections, or arrange a form yourself in the view |
| [Multiple choices](multiple-choices.md) | Let people tick several options or pick several from a list, and store the result |
| [File uploads](file-uploads.md) | Accept photos or documents safely and store them |
| [Custom field types](custom-field-types.md) | Add a field of your own, such as an amount with a currency, and use it like a built-in |
| [Customising views](customising-views.md) | Change classes, edit the HTML of fields, or create a theme of your own |
| [Option providers](option-providers.md) | Fill a select or checkbox group from your database |
| [Forms written by admins](forms-written-by-admins.md) | Let admins and clients create forms, safely, without code |
| [Showing submissions](showing-submissions.md) | Show stored answers with labels and option texts |
| [Testing your forms](testing-your-forms.md) | Test form classes and the controllers that use them |
| [JavaScript and APIs](javascript-and-apis.md) | Validate JSON, return errors as JSON, and handle genuine PATCH requests |

New to the package? Start with [Getting started](../getting-started.md).
